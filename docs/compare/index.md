# Compare frameworks with evidence

This is the comparison space. It keeps product selection and benchmark evidence separate from the framework-neutral learning path.

## Start with your decision

| Your question | Go here |
|---|---|
| What has the project actually measured? | [Measured findings](../findings.md) |
| Which framework fits my constraints? | [Decision guide](../decision-guide.md) |
| Does a framework support a capability? | [Feature matrix](../feature-matrix.md) |
| How much machinery does it add? | [Framework overhead](../overhead.md) |
| What does delegation cost? | [Multi-agent comparison](../multi-agent.md) |
| How does it behave when a provider fails? | [Transport failures](../transport.md) |

!!! warning "Evidence boundary"
    Mock results compare wiring, framework overhead, recovery mechanics, and pause behavior. They do not rank answer quality. A native live scorecard is required for claims about model quality, latency, tokens, or provider cost.

## A useful order

1. Read [Findings](../findings.md) for the known answer.
2. Check [Methodology](../methodology.md) before trusting a number.
3. Use the [Decision guide](../decision-guide.md) to apply the evidence to your constraints.
4. Open framework and arena reference pages only when you need detail.

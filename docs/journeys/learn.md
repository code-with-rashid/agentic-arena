# Learn the mechanics

Understand what an agent harness must own before choosing libraries.

## Questions to answer

Which parts are model decisions? Which are deterministic runtime behavior? Who owns state and authority?

## Start here

Read [the architecture guide](../concepts/architecture.md), then trace the [vanilla adapter](../../frameworks/vanilla/adapter.py). Follow the build journey once messages, actions, and effects are distinct.

Prerequisites: a small task you can describe, its permitted effects, and basic Python for executable examples. Reading the guides needs no API key.

# Deploy and operate

Turn local behavior into bounded, recoverable work.

## Questions to answer

What survives a crash? Can retries duplicate a side effect? Who releases resources after failure?

## Start here

Read [durable-state mechanics](../arenas/durable_state.md) and [provider failure behavior](../transport.md). Specify timeout, cancellation, concurrency, identity, secrets, and cleanup ownership before selecting infrastructure.

Prerequisites: a small task you can describe, its permitted effects, and basic Python for executable examples. Reading the guides needs no API key.

# Evaluate a design

Choose evidence that answers a concrete decision.

## Questions to answer

What is held constant? What is the independent oracle? What result would disprove my claim?

## Start here

Read [methodology](../methodology.md), [fairness controls](../fairness-controls.md), and [findings](../findings.md). Run python -m arena validate and a vanilla mock arena before designing a new comparison.

Prerequisites: a small task you can describe, its permitted effects, and basic Python for executable examples. Reading the guides needs no API key.

## Evidence and coverage

# Personal Obsidian Area

This guide is public. Other files in this directory are ignored by Git. Use them for personal understanding, questions, learning records, and private ideas for the future harness.

The initial local note is named `direction-and-learning.md`. Open it in Obsidian's file explorer. It is deliberately not required for public navigation.

Suggested records:

- Direction and learning: why this route, what I want to understand.
- Learning journal: concept, explanation in my words, experiment, uncertainty.
- Harness ideas: problem, candidate design, tradeoff, required experiment.
- Review notes: issue/PR, what changed, and implications for my plans.

Private reflections are not published project decisions. Promote reusable evidence intentionally after removing personal material.

Ignored files remain on this machine unless separately backed up privately. Git ignore prevents routine inclusion, not local application access. Do not store credentials here. Shared research and strategy belong in versioned directories.

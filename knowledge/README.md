## How to read the vault

A repository's documented purpose is a source claim. A suggested integration is our proposal. Only an experiment with a linked run artifact is a local measurement. Broad coverage is the destination; blank areas in the map are research backlog, not implemented capabilities.

The vault owns research synthesis and direction. Existing source, tests, results, and public docs remain authoritative for implementation and published measurements. Links to those artifacts avoid maintaining duplicate score tables. External links may point at moving branches; pin revisions before implementation or numerical comparisons.

For Obsidian graph navigation, follow Markdown links and filter by `path:projects` or `path:strategy`. Shared app settings prefer relative Markdown links; personal workspaces and plugin files are ignored.
